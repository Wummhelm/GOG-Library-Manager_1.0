# Security Policy

## Supported versions

The current stable release is 1.0.

## Reporting a security issue

Please report security-sensitive issues privately to the repository maintainer rather than opening a public issue containing credentials or other secrets.

If GitHub Private Vulnerability Reporting is enabled for the repository, use that feature.

## Credentials

Never include Twitch/IGDB Client IDs, Client Secrets, OAuth tokens, local configuration files or other secrets in bug reports, screenshots, commits or pull requests.

The project does not require credentials to be stored in the source tree.
